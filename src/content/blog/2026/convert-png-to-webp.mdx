I want to show you my 2 main methods for converting `.png` files to `.webp` format. 
Whether I want a quick browser-based conversion or a full batch script from the terminal, 
I choose the method that best suits my needs.

## 1. Method: EZGIF

1. Go to <a href="https://ezgif.com/png-to-webp" target="_blank" rel="noopener noreferrer">ezgif.com/png-to-webp</a>
2. Upload your PNG file.
3. Click **Convert to WEBP!**
4. Download your webp.

> No software installation is required. The site handles the conversion in the browser. Output settings like quality can be adjusted before converting.  
> Good for quick single-file conversions when you don't want to open the terminal.

## 2. Method: MAGICK

### Bulk Conversion

```bash
for f in *.png; do
 magick "$f" -resize 50% -quality 90 "${f%.png}.webp"
done
```

### Single File Conversion

```bash
magick source.png -resize 80% -quality 80 destination.webp 
```

## What the command does

- `magick` launches ImageMagick
- `"$f"` safely handles filenames with spaces
- `-resize` scales the image of its original size
- `-quality` sets the WEBP quality
- `"${f%.png}.webp"` replaces the `.png` extension with `.webp`

> Requires ImageMagick installed. Fast, scriptable, and produces high-quality output. Good for terminal users who need to convert many files at once.
