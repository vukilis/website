So basically I was getting tired of all those bloatware and background processes that keep coming 
with Windows 11 each time I was setting up a new machine, so I thought why not create my own tool 
for that.

I have created [Windows11-Optimizer-Debloater](https://github.com/vukilis/Windows11-Optimizer-Debloater), where you can clean all the 
unnecessary installations, optimize performance of your system, and configure the system according 
to your needs. Just wanted to put this forward for people who are looking for ways to improve 
performance and clean up the Windows clutter.

## One Command - Download and Usage

Requires you to launch PowerShell or Windows Terminal As **ADMINISTRATOR!**

Launch Command:

```powershell
iwr -useb vukilis.com/win11deb | iex
```

If you are having TLS 1.2 Issues or You cannot find or resolve `vukilis.com/win11deb` then run with the following command:

```powershell
[Net.ServicePointManager]::SecurityProtocol=[Net.SecurityProtocolType]::Tls12;iex(New-Object Net.WebClient).DownloadString('https://raw.githubusercontent.com/vukilis/Windows11-Optimizer-Debloater/main/win11deb.ps1')
```

## Parts of Utility

This utility show basic system information, install programs, debloat and optimize Windows with tweaks, troubleshoot with config, and fix Windows updates.

### **INFO** 

- Show basic system information about OS and hardware.

Right out of the box, the software will show you a fresh picture of your system specifications and the operating system specifications, giving you an idea of the hardware that you have before making any changes.

### I**NSTALL** 

- Install/Uninstall/Upgrade winget, chocolatey and python packages

it manages your package management from one single place. Installing, updating or deleting software becomes easy using winget, chocolatey, and python packages without the need to go through the command prompt for each different package manager.

- Removes all necessary pre-installed apps comes with Windows
