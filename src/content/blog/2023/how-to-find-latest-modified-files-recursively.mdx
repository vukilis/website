## Script

last_modified_files.sh

```ini frame="terminal"
echo -ne "\n"
echo -ne "date created  | time modified  | file name
------------------------------------------\n"
find . -mindepth 1 -printf '%T@\t%P\n'|  tail -n 10 |\
        sort -nr -k1|\
        awk -F\\t '
          {
            topdir=$2;
            gsub(/\/.*/, "", topdir);
            if (topdir=="") { topdir="." };
            if (!seen[topdir]) { 
              seen[topdir]=1;
              print strftime("%Y.%m.%d    | %Hh:%Mm",$1) "        | " $2;
            }
          }'
```

## Example

```bash
chmod +x last_modified_files.sh
./last_modified_files.sh
```
